# 萌宠 homePlay

微信开发者工具导入项目根目录即可预览单人玩法和本机宠物档案。项目自带的是演示登录；在线 PK 使用云函数取得微信 OpenID 来识别玩家。

## 开通地区 PK

1. 在微信开发者工具中为当前小程序 AppID 开通并关联微信云开发环境。若需指定环境，在 `miniprogram/utils/pk-client.js` 中填写 `ENV_ID`。
2. 在该环境的云数据库里创建 `pet_pk_nests` 和 `pet_pk_rooms` 两个集合。两个集合都应设置为**仅管理员可读写**（客户端通过云函数访问）。房间文档包含所有玩家手牌，不能对客户端开放数据库读权限。
3. 在开发者工具中右击 `cloudfunctions/petPk`，选择上传并部署（云端安装依赖）。如果云控制台针对查询提示创建索引，按提示创建。小窝列表使用 `open`、`seen`；房间列表按座位字段 `p0` 至 `p3`、`status`、`updated` 查询。
4. 用不同的微信账号分别进入小程序，在「我的」设置昵称、地区并打开「在线时公开小窝」。到「地区」串门发起 PK，受邀玩家可在「地区 → 我的邀请与对局」中接受。斗地主需要三位玩家，麻将需要四位玩家。跑步闯关由发起人选地图、每位玩家选一只自己拥有的萌宠，再由发起人开局。

小窝仅在公开且最近 45 秒有在线心跳时可访问。邀请等待 3 分钟后过期；活跃对局可从地区页重新进入。麻将采用四人自摸场规则（无吃、碰、杠、点炮）。目前宠物档案和积分保存在本机，历史旧存档只可补录赠送的中华田园犬和迁移时的当前宠物。

运行 `node --test tests/play.test.js tests/pk-flow.test.js` 可验证连连看、PK 核心规则、模拟云端邀请流程和旧存档迁移。云端部署后，用两个账号验证邀请接受、拒绝、隐藏小窝和五子棋/知识竞速/闯关同步，再用三个或四个账号验证牌局。
