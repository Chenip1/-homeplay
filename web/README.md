# 萌宠 homePlay 网页版

在项目根目录使用 Node.js 24 运行：

```powershell
npm run web:dev
```

在浏览器打开 http://127.0.0.1:4173 。网页复用小程序页面、素材和游戏逻辑。网页的宠物档案、积分、背包和相册保存在当前浏览器，首次进入会建立独立存档。

本地服务包含地区 PK。用两个独立浏览器或浏览器配置分别进入网页，在「我的」设置不同昵称并打开「在线时公开小窝」，再到「地区」邀请对方。斗地主需三个玩家，麻将需四个玩家。局域网联机可在启动前把环境变量 `HOMEPLAY_HOST` 设为 `0.0.0.0`，其他设备通过运行服务的电脑的局域网地址访问。房间保存在服务进程内，重启服务后需要重新开局。

`npm run web:build` 生成可部署到域名根路径的 `web/dist` 静态目录。静态部署提供单人玩法，地区 PK 需使用配套的 Node 服务。
